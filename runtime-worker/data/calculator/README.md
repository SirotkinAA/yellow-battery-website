# База из готовых листовок YELLOW

Версия `leaflets-2026-09-23-v1`. Источник согласован пользователем в этой задаче: «давай делать базу данных из листовок в соседней ветке». Это заменяет прежнее ограничение источника для данного импорта. Старый audit JSON не читается импортёром.

- 26 моделей из `output/catalogue/manifest.json`; обозначения HR и HRL сохранены дословно. Семейства калькулятора HR-M / HR-WM определены по суффиксам M / WM.
- Из PDF непосредственно извлечено 2844 числовых значения, 276 строк таблиц.
- Активны 271 строка / 2764 значения. 5 токовых строк / 80 значений HRL 12-22WM сохранены в карантине: при 6 ч ток 1,60 В/элемент ниже, чем при 1,67 В/элемент. Мощностные строки этой модели проверены и доступны.
- `leaflets-v1.sqlite` — нормализованная локальная база: модели, источники, кривые, точки, карантин. `leaflets-v1.json` — согласованный с ней снимок для Python/Cloudflare Worker. Изменения выполняются через повторный проверяемый импорт, не редактированием JSON на сайте.
- `leaflets-provenance.json` — PDF, SHA-256, страница, исходный OEM-файл, примечания и паспортный кратковременный ток.
- `leaflets-quarantine.json` — неизменённые спорные значения и причины исключения.
- Импортёр: `tools/build_calculator_leaflet_database.py`, Python + pdfplumber. Он читает печатные таблицы страницы 3 и номинальные данные страницы 1. Значения W/cell уже приведены в листовках; повторного деления на 6 нет. Ток сохраняется в амперах. Часы переводятся в минуты.
- Температура HR 12-40WM: 20 °C. Остальные: 25 °C. Интерполяции между температурами и напряжениями нет.
- Паспортные токи за 5 секунд не используются как допустимые токи многоминутного режима, клемм, перемычек или защиты. Поэтому `current_check=not_checked`.
- Статус `approved` означает разрешённые для этой тестовой базы данные из согласованного пользователем комплекта, прошедшие структурную проверку. Это не сертификация изделия или независимая инженерная приёмка. Mathcad parity остаётся незавершённой, `production_ready=false`.

Сайт читает серверный снимок. SQLite не опубликована как доступный для записи файл. D1 и административный интерфейс пока не созданы.
