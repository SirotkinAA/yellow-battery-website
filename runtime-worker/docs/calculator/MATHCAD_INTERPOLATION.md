# Исправление интерполяции — 25.09.2026, ядро 0.2.0

В обоих исходных файлах пользователя (`IEEE-485 по мощности.mcdx`, `Время разрядо по IEEE-485.mcdx`) XML mathcad/worksheet.xml содержит:

- `f(d) = interp(lspline(DC⟨1⟩, DC⟨2⟩), DC⟨1⟩, DC⟨2⟩, d)` для разрядной характеристики;
- в обратной задаче `root(f(T) - Cном/DF, T)`;
- отдельно `cspline` для исторической температурной поправки. Эта таблица не импортирована и температурные поправки не меняются.

Документация PTC: https://support.ptc.com/help/engineering_notebook/r12.0/en/PTC_Mathcad_Help/cubic_spline_interpolation.html — lspline является кубическим сплайном с нулевой второй производной в крайних узлах. Прежняя спецификация ошибочно приравнивала его к кусочно-линейной интерполяции.

Ядро строит естественный кубический сплайн по всей строке мощности/времени. Коэффициенты находятся трёхдиагональным решением; обратная задача — ограниченным поиском корня этого же сплайна. Узлы сохраняются без округления. Экстраполяция остаётся запрещена согласно ранее согласованным границам калькулятора (это намеренное отличие от возможности Mathcad экстраполировать).

Монотонность проверяется по максимумам квадратичной производной каждого сегмента, включая внутренние экстремумы. Обнаружены пять немонотонных сплайнов мощности HRL 12-22WM (1.60, 1.67, 1.70, 1.75, 1.80 В/элемент). Исходные табличные данные не изменены. Такие кривые исключаются из расчётов автономии и профиля с кодом nonmonotone_spline и видимым уведомлением. Это не доказательство ошибки листовки: естественный сплайн не гарантирует сохранения монотонности входных узлов. Подмена на PCHIP/линейный метод не производится.

Проверки: аналитические трёхточечные примеры с равномерной и неравномерной сеткой, прямая/обратная задача, профиль на нелинейном участке, сохранение всех узлов 271 кривой, обратный расчёт в трёх внутренних точках каждого интервала 266 монотонных кривых. 51 тест калькулятора проходит.

Пример HR 12-18M, 10 кВА, PF=0.9, КПД=93%, 20 АКБ в линейке, одна параллель, 25°C, 1.80 В/элемент: линейный результат 8.472 минуты; новый сплайн 8.15602927945 минуты (вывод 8.156). Это сравнение двух алгоритмов на новых данных, а не результат исполнения Mathcad.

Полный контрольный прогон внутри приложения Mathcad на новых одинаковых данных ещё не выполнен; mathcad_parity_pending сохраняется. Версия алгоритма и interpolation=mathcad_lspline_natural_cubic записываются в JSON результата.
