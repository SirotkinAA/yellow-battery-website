# Кабинет YELLOW: тестовая версия

Адрес: https://test.yellow-battery.com/admin/
Первый администратор: admin@yellow-battery.com. Пароль назначает сам владелец по одноразовой ссылке (24 часа). Готового пароля в исходниках нет.

## Партнёры и права

Партнёр оставляет заявку в публичной форме кабинета. Администратор одобряет или отклоняет её, назначая отдельно:

- `prices:read` — доступ к ценам. Таблица предусмотрена, цены пока не загружены.
- `api:export` — выгрузка каталога с разрядными характеристиками.
- `widget:embed` — настройка и размещение калькулятора.

Одобрение создаёт одноразовую ссылку установки пароля. На первом этапе администратор передаёт её партнёру самостоятельно: автоматическая отправка email не подключена. Ссылку нельзя публиковать. Повторная выдача отменяет предыдущую. Установка пароля завершает действующие сессии.

## База характеристик

Исходная утверждённая версия: HR-M / HR-WM, 26 моделей. Кабинет показывает модель и её таблицы в JSON, поддерживает импорт набора, проверку и публикацию новой ревизии. Публикация проверяет структуру и статусы строк, а не достоверность инженерных значений: их должен сверить администратор. Одновременное обновление другой сессией блокирует перезапись устаревшей ревизии.

Ревизии сохраняются целиком в D1; калькулятор и API используют активную ревизию. До первой публикации используется исходный набор из сборки. Непринятые строки из карантина не включены. Это не снимает ограничений точности и незавершённой проверки IEEE-485, описанных в документации калькулятора.

## API

Создать ключ в разделе API. Он показывается один раз, действует 90 дней, отзывается в кабинете. Хранить только на сервере партнёра, не в JavaScript сайта или iframe.

```sh
curl https://test.yellow-battery.com/partner-api/v1/catalog \
  -H 'Authorization: Bearer YOUR_SERVER_SIDE_KEY'
```

Ответ содержит dataset_id, revision, models и curves. Внутренние пути источников исключены. Цены добавляются лишь при наличии права пользователя и области `prices:read` у ключа. Ограничение: 60 запросов в минуту на ключ. Отзыв прав владельца действует при следующем запросе. Публичный JSON расчёта больше не содержит целиком исходную базу.

## Виджет

Конфигуратор задаёт заголовок, RU/EN, цвета, шрифт, скругление и доступные режимы. После сохранения выдаёт iframe и предпросмотр. Для каждого сайта указать точный HTTPS origin (поддомены отдельно). CSP frame-ancestors ограничивает встраивание этими адресами; это ограничение браузерного встраивания, а не секретность публичного калькулятора. API-ключ виджету не нужен. Высота iframe настраивается в коде вставки; автоматическое изменение высоты пока не реализовано.

## Хранение и эксплуатация

Cloudflare D1 `yellow-battery-portal-test`, binding `PORTAL_DB`. Пользователи, хеши паролей, сессии, заявки, ключи, виджеты, ревизии и журнал действий хранятся отдельно от статических страниц. Схема: `battery_portal/schema.sql`.

Пароли: PBKDF2-HMAC-SHA256, 600000 итераций, случайная соль. На Cloudflare используется серверный Web Crypto; в локальном Python — hashlib. Сессия: 8 часов, HttpOnly/Secure/SameSite=Strict, CSRF и проверка Origin. Ключи, сессии и ссылки в базе представлены хешами. Есть ограничения попыток входа и подачи заявок. Администратор не может отключить последнего активного администратора. Роли и права проверяются на сервере.

Для первого пользователя нет публичного bootstrap endpoint. Оператор создаёт запись без пароля и хеш одноразового приглашения только в пустой базе. Секретную ссылку передаёт владельцу лично. Не хранить SQL с приглашением или ссылку в Git.

Локальный кабинет: `/admin/` на сервере калькулятора. Локальная SQLite находится в `.local/portal.sqlite` и не входит в Git. Тесты используют отдельные временные базы. Проверено: 46 тестов калькулятора, 10 тестов кабинета и полный сценарий на локальном Cloudflare Worker/D1 (установка пароля, вход, одобрение, API/отзыв, iframe/CSP).

До перехода с тестового домена на основной: настроить доставку писем, резервирование и обслуживание сроков хранения журнала/заявок; провести независимую проверку безопасности. MFA и самостоятельное восстановление пароля по email пока не реализованы: ссылку выдаёт администратор.
