Это предварительный состав по каталожным лимитам. Исполнения датчиков, напряжение цепей, питание, токи, кабели и лицензии проверяются перед окончательной спецификацией. Многополюсные и неодинаковые цепи требуют отдельного расчёта.This is a preliminary configuration based on catalogue limits. Sensor versions, string voltages, power, current ratings, cables and licences are checked before the final specification. Multi-pole batteries and unequal strings require a separate calculation.
