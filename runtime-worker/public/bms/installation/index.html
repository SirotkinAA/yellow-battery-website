YELLOW PBMS9000 / EN

Настройка контроллера.Controller setup.

Веб-интерфейс, параметры системы, карта батарей и события.Web interface, system settings, battery mapping and events.

Порядок подключения и настройки сверяйте с документацией выбранного исполнения оборудования.Check the wiring and setup procedure against the documentation for the selected equipment version.

  1. 01

    Спецификация и совместимостьEquipment and compatibility

    Контроллер, датчики по типу и напряжению АКБ, модули цепей, питание, кабели и интерфейсы.Controller, battery-compatible sensors, string modules, power supplies, cables and interfaces.

  2. 02

    Утверждённая схема объектаApproved site wiring design

    Подключение выполняется квалифицированным персоналом по документации выбранного исполнения.Qualified personnel must follow the documentation for the selected equipment version.

  3. 03

    Адреса и карта батарейAddressing and battery map

    Сопоставить идентификаторы датчиков с фактическими АКБ и цепями.Map sensor identifiers to physical batteries and strings.

  4. 04

    Проверка измеренийMeasurement verification

    Проверить корректность показаний по документации и зафиксировать исходные значения.Verify readings against the equipment documentation and record baseline values.

  5. 05

    Пороги и диспетчеризацияThresholds and supervision

    Согласовать уставки для применяемых батарей и проверить передачу событий.Agree thresholds for the installed batteries and verify event delivery.

  6. 06

    Передача в эксплуатациюOperational handover

    Сохранить карту датчиков, настройки и резервную копию конфигурации.Save the sensor map, settings and configuration backup.

Этот порядок не заменяет монтажную документацию конкретного исполнения. Схемы на сайте показывают обмен данными.This workflow does not replace the installation documentation for a specific equipment version. Site diagrams show functional data flow.
