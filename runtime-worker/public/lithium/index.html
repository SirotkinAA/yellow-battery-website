Как считается результатCalculation method

E = P × t / 1000; Ebat = E × (1 + R / 100) / (η / 100) / (D / 100); C = Ebat × 1000 / U; I = P / (U × η / 100).

P — нагрузка, t — время, U — напряжение, η — КПД, D — используемая доля ёмкости, R — запас. Для нагрузки постоянного тока без преобразователя задайте КПД 100%.P is load, t runtime, U voltage, η efficiency, D usable capacity and R margin. For a DC load without a converter, set efficiency to 100%.

Для окончательного подбора нужны диапазон напряжений инвертора и зарядного устройства, допустимые токи и мощность батареи, ограничения BMS, температура и условия монтажа. Последовательное и параллельное соединение допускается только по документации производителя.Final selection requires inverter and charger voltage ranges, battery current and power limits, BMS limits, temperature and installation conditions.
