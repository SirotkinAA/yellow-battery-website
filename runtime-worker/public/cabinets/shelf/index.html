Исходные данные

Размеры и масса из каталога — номинальные. Прибавка увеличивает каждый габарит АКБ целиком; массу можно увеличить вручную с учётом допуска. Зазоры 10 мм — начальное допущение, их нужно проверить по требованиям батареи и подключения.

АКБ стоят вертикально. Сравниваются прямоугольные сетки с единой ориентацией; смешанное размещение не рассчитывается.

Компоновка шкафа

Предварительный расчёт

Модель, габариты, масса и общее количество АКБ берутся из формы выше. Шкафы заполняются последовательно, полки — снизу вверх. Последний шкаф может быть неполным. Распределение геометрическое: электрические цепи и межшкафные соединения пока не учитываются.

Параметры по высоте

Отметки — от низа корпуса. 100 / 1900 мм и зазор 100 мм — допущения для эскиза. 25 мм по высоте полки — редактируемое допущение. CAD-габарит ≈24,5 мм измерен только для 9692.020; для других полок он не подтверждён. Шаг уровней округляется вверх до 25 мм по сетке рамы. Соответствие опорных плоскостей монтажным отверстиям не подтверждено.

Резерв под коммутацию

Геометрический резерв на всю ширину и глубину, одинаковый в каждом шкафу. Положение, разделение и вентиляция не подтверждены. Масса отсека добавляется отдельно; при «Без отсека» эти параметры не учитываются.

Общая масса на один шкаф

Лимит сравнивается с массой АКБ, полок, коммутации и прочей комплектации, без массы выбранного корпуса. Пустое поле означает «не проверено». Введённый лимит не становится паспортным значением Rittal и не меняет геометрическую раскладку.

Вид сверху выбранной полки

На виде спереди видимые колонки условно объединены по глубине; фактическая расстановка показана сверху.

3. Соединения и перемычки

Расчёт для выбранной компоновки. Электрическая линейка — последовательная цепь; она может занимать несколько рядов и ярусов.

Кабели, наконечники и монтажные запасы

Считаются внутренние соединения выбранной компоновки. Кабели к размыкателю, ИБП и между шкафами требуют координат аппаратов и отдельной трассы. Длина трассы с запасом не является длиной отрезка провода для изготовления.

Электрические потери по полученным длинам

Без заданного тока выдаётся геометрия. Контакты, нагрев и допустимый ток не проверяются.

Границы расчёта

Это предварительная геометрическая компоновка. Расчёт не подтверждает доступ к клеммам, трассы кабелей, вентиляцию и распределение нагрузки по опорной поверхности. Расстановка центрирована; остаток ряда также центрирован.

Число полок рассчитано по введённым допущениям; ведомость компонентов неполная. Монтажные уровни и общая нагрузка шкафа требуют проверки. В источниках по раме есть расхождение: 10 000 и 15 000 Н; автоматически выбирать одно значение пока нельзя.
